Settings

Two subjects are joined by an edge when at least one student takes both. The backtracking colouring then finds the minimum number of slots so that no student has two exams at once. Sundays are skipped.

Backtracking vs Greedy

Greedy (Welsh–Powell) is fast but may use extra slots. Backtracking tries m = 1, 2, 3… so the first m that works is the true minimum (chromatic number).

Complexity

Build graphO(S·k² ) for S students, k subjects each
BacktrackingO(mV) worst case, pruned by degree ordering & symmetry breaking
GreedyO(V² )
SpaceO(V + E)
